# Grok bot — briefing diario

O bot **nao** grava no Google Sheets (nao ha conector Drive nesta conta). Ele produz o briefing e o CSV; o pipeline Python e o que publica a planilha.

## O que o bot faz bem

- Conferencia humana/LLM da rodada.
- Texto para LinkedIn / README ("acompanhamento autonomo").
- Alerta se a API atrasar.

## Agenda sugerida

- Diario 08:00 America/Sao_Paulo.
- Extra 23:30 nas noites de rodada (quarta, sabado, domingo) se quiser.
